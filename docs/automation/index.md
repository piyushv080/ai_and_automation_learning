# Automation Learning

Use this section for notes on automation tools and techniques, such as Python scripting, Ansible, shell scripting, APIs, and CI/CD.

## Note template

For each topic, describe:

- What problem the tool or technique solves
- The main concepts and commands
- A small, safe example
- Common errors and how to troubleshoot them
- Links to official documentation

Add each new Markdown file to the Automation section in `mkdocs.yml` so it appears in the site navigation.
