# 100 Days of Code

**Official start date: 15 November 2026**

Welcome to this 100-day practical Python and cloud automation learning journey.

## Goals

- Improve Python programming and testing skills.
- Build practical infrastructure and cloud automation tools.
- Learn CI/CD and GitHub Actions through hands-on work.
- Maintain a public, reviewable record of progress.

## Submission workflow

1. Solve the challenge in `solutions/day-NNN/`.
2. Add pytest tests and a short README.
3. Push the solution to the configured solution branch.
4. Comment `/submit` on the challenge issue.
5. Review the validator feedback.
6. Comment `/complete` after reviewing your own work.

Progress is tracked using GitHub Issues and labels.
