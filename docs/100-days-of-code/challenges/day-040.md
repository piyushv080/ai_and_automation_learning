# Day 040 — Cloud Cost Aggregator

## Scenario

Aggregate sample cloud spend by service, owner and environment.

## Objectives

Build a Python solution that addresses this scenario.

1. Implement and test: Aggregate sample cloud spend by service, owner and environment.
2. Implement and test: Handle missing, malformed and boundary-case input.
3. Implement and test: Separate reusable logic into functions with clear return values.
4. Implement and test: Provide useful output that another engineer can understand.
5. Implement and test: Write automated tests for success and failure scenarios.

## Requirements

- Use Python 3.12 or newer.
- Prefer the Python standard library unless a dependency is justified.
- Validate input rather than assuming it is correct.
- Keep business logic separate from command-line or display code.
- Do not hard-code credentials, tokens, or sensitive values.
- Add pytest tests for valid input, invalid input, missing data and edge cases.
- Include a short README explaining how to run the solution and tests.
