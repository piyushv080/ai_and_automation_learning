
# Day 1 — Server Resource Validation

## Scenario

You receive server information from an external infrastructure API.

Example input:

```python
server = {
    "hostname": "web-server-01",
    "cpu": "4",
    "memory": "16",
    "environment": "production"
}
```

## Objectives

Build a Python program that validates the server information.

Your program should:

1. Extract the hostname.
2. Convert CPU and memory values to integers.
3. Check that CPU is greater than zero.
4. Check that memory is greater than zero.
5. Handle invalid values safely.
6. Identify missing dictionary keys.
