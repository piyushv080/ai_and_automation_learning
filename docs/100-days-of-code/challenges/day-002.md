
# Day 2 — Server Inventory Processing

## Scenario

You receive a list of servers from an infrastructure inventory.

```python
servers = [
    {"hostname": "web-01", "environment": "production", "cpu": 4},
    {"hostname": "web-02", "environment": "development", "cpu": 2},
    {"hostname": "db-01", "environment": "production", "cpu": 8}
]
```

## Objectives

1. Iterate through the server inventory.
2. Identify production servers.
3. Count the total number of production servers.
4. Calculate total CPU capacity.
5. Handle an empty inventory.

- Lists
