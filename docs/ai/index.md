# AI Learning

Use this section for notes on AI and machine learning concepts, tools, and experiments.

## Note template

For each topic, describe:

- The problem or concept
- Important terms and a small example
- What you tried and what you observed
- Limitations, safety, or data privacy considerations
- Links to official documentation

Add each new Markdown file to the AI section in `mkdocs.yml` so it appears in the site navigation.
