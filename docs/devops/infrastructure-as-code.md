# Infrastructure as Code

Infrastructure as code describes environments in versioned files so changes can be reviewed, tested, and reproduced. Combine cloud concepts with Terraform to manage infrastructure safely.

## In this category

- [Cloud Infrastructure](cloud/cloud-infrastructure.md) — identity, compute, networking, storage, operations, and cost.
- [Terraform Foundations](automation/terraform.md) — providers, resources, plans, state, and modules.

## Suggested order

1. Learn the cloud building blocks and design habits.
2. Write a small Terraform configuration for a non-production resource.
3. Review the plan, apply it, verify the result, then destroy the resource.
