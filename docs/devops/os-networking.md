# Operating System & Networking

Operating-system and networking fundamentals underpin almost every automation task. Learn how Linux behaves, how services are managed, and how traffic moves between hosts before automating changes.

## In this category

- [Linux Foundations](cloud/linux-notes.md) — shell, permissions, processes, disks, logs, and troubleshooting.
- [Networking Foundations](cloud/networking-notes.md) — packet flow, addressing, routing, DNS, HTTP, and firewalls.

## Suggested order

1. Start with Linux Foundations and practice the commands on a test system.
2. Move to Networking Foundations and trace how a web request reaches a server.
3. Combine both by deploying a small service and verifying its network path.
