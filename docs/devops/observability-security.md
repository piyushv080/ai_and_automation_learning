# Observability & Security

Observability shows whether a service is healthy; security controls reduce risk in the delivery path and at runtime. Treat both as part of normal operations, not an afterthought.

## In this category

- [Prometheus and Grafana Guide](prometheus-grafana-guide.md) — metrics, queries, dashboards, and alerts.
- [Security and Observability](security-observability.md) — logging, monitoring, scanning, and operational safeguards.

## Practice

1. Add metrics and a dashboard for a small test service.
2. Create an alert for a meaningful service indicator.
3. Add dependency and configuration scanning to a pipeline.
4. Document a rollback and incident-response path in a runbook.
