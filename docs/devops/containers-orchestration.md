# Containers & Orchestration

Containers package an application with its dependencies; orchestration runs and scales those containers reliably. Learn the commands first, then the platform concepts.

## In this category

- [Docker Commands Cheat Sheet](docker-guide.md) — images, containers, volumes, networks, and cleanup.
- [Kubernetes Guide](kubernetes-guide.md) — pods, deployments, services, configuration, and operations.

## Suggested order

1. Build and run a small container locally with Docker.
2. Push an image and run it from a registry.
3. Deploy it to a test Kubernetes cluster and verify health, logs, and rollback.
