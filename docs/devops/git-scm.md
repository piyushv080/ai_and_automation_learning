# Git SCM

Git is the source-control system behind most automation and delivery workflows. Use it to track changes, review work, and version scripts, configuration, and infrastructure definitions.

## In this category

- [Git Guide](git-guide.md) — repositories, commits, branches, merging, remotes, and recovery.

## Practice

1. Create a repository for a small script.
2. Commit changes with clear messages.
3. Create a branch, make a change, and open a pull request or review.
4. Practice reverting a change and reading history.
