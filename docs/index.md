## Suggested learning paths

### Start with scripting

1. Learn [Python basics](scripting/python-basic.md), then try the [Python advanced guide](scripting/python-advanced.md).
2. Practice shell commands with [Bash and shell](scripting/bash.md).
3. Pick up [PowerShell](scripting/powershell.md) for Windows administration.

### Build infrastructure skills

1. Review [Linux administration](devops/cloud/linux-notes.md) and [networking](devops/cloud/networking-notes.md).
2. Learn the concepts in [Cloud Infrastructure](devops/cloud/cloud-infrastructure.md).
3. Automate repeatable changes with [Ansible and AWX](devops/automation/ansible-awx.md).
4. Follow the [DevOps & Infrastructure as Code](devops/devops-engineering.md) path and build a project from the [catalog](projects/project-ideas.md).

## How to use this library

Start with a topic overview, follow a small example, then adapt it into a project. Keep notes about assumptions, errors, verification steps, and what you would improve next. Examples are for learning; review commands and credentials before using them in a real environment.
