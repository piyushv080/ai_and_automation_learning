## Suggested learning paths

### Start with scripting

1. Learn [Python basics](python-basics.md), then try the [Python infrastructure guide](python-infrastructure-automation.md).
2. Practice shell commands with [Bash and shell](scripting/bash.md).
3. Pick up [PowerShell](scripting/powershell.md) for Windows administration or [JavaScript](scripting/javascript.md) for web and Node.js automation.

### Build infrastructure skills

1. Review [Linux administration](linux-notes.md) and [networking](networking-notes.md).
2. Learn the concepts in [Cloud Infrastructure](cloud/index.md).
3. Automate repeatable changes with [Ansible and AWX](ansible-awx.md).
4. Follow the [DevOps Engineering](devops/index.md) path and build a project from the [catalog](projects/index.md).

## How to use this library

Start with a topic overview, follow a small example, then adapt it into a project. Keep notes about assumptions, errors, verification steps, and what you would improve next. Examples are for learning; review commands and credentials before using them in a real environment.
